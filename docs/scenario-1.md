# 시나리오 1: 저장·조회 (Phase 1)

[← README](../README.md)

## 유저 스토리
- **누가**: 개발자
- **무엇을**: 데이터를 저장하고 조회한다.
- **왜**
  - 데이터를 안전하게 오래 보관하려고
  - 사용한 데이터를 저장해 두려고
  - 아무나 데이터에 접근하지 못하게 관리하려고 (→ 범위 밖, [README](../README.md#범위-밖))

## 완료 조건과 결과
| 완료 조건 | 결과 |
| --- | --- |
| 데이터를 디스크에 파일 형태로 저장 | `data/<table>.schema` + `data/<table>.csv` |
| 데이터 조회 | `SELECT`. 없는 값이면 헤더 + `0 rows` |
| SQL로 접근 | INSERT, SELECT 지원 |
| 대소문자 구분? | 키워드는 구분하지 않음 |
| 잘못된 명령어? | 첫 오류에서 멈춤, 앞 문장 결과는 남음 |

## 써 보며 겪은 한계와 고친 것
| 겪은 일 | 처리 |
| --- | --- |
| SQL 주석을 쓰면 오류 | `--`, `/* */` 주석 지원 추가 |
| 공백 없이 붙여 쓴 SQL(`INSERT INTOstudents`)은 실패 | SQL 문법상 당연한 동작이라 그대로 둠 |
